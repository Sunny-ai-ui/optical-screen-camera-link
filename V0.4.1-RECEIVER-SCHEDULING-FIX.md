# v0.4.1 Receiver Scheduling Fix

This release addresses the physical-phone failure observed with strong locator tracking but zero optical/RS decode attempts.

## Root causes fixed

1. **Temporal evidence expired too quickly.** The receiver used a ~1.3 s observation lifetime while physical phone decoding measured roughly 0.7–0.9 s per observation. A six-observation target could therefore be unreachable.
2. **RS was attempted too late.** Low adaptive link scores could require six observations even when individual observations were already close to the learned quality gate.
3. **Worker skip storm.** The capture loop resumed at 90 ms while the decoder worker needed hundreds of milliseconds, creating many redundant `decoder busy` passes.
4. **Density lock changed too easily.** A single coarse signature change could switch G32/G48/G64 and reset transfer/calibration state.
5. **Calibration separation diagnostics disappeared after fusion.** Raw observations contained valid colour/shape separation values, but the temporal fused observation did not propagate them, so the UI showed `0.000`.

## v0.4.1 behavior

- Temporal evidence lifetime is computed from measured decoder latency and adaptive evidence target, bounded to 2.2–8.5 seconds.
- A weak link can still retain a full adaptive target of up to six observations, but RS begins progressively at four near-gate observations or three strong observations.
- Ready calibration gets a bounded 3% quality-gate tolerance to prevent threshold jitter from discarding otherwise useful evidence.
- Busy-loop scheduling follows measured worker latency instead of polling every 90 ms.
- Profile changes require four consecutive valid coarse detections before the receiver changes density.
- Fused diagnostics retain colour calibration separation, shape calibration separation, low-confidence rate, and calibration scale.
- The optical wire format, RS(15,11), fountain transport, and one-way sender→receiver architecture are unchanged.

## Expected physical test

Start with G32, Resilient Fountain, and ~1000–1200 ms sender dwell. At ~14–18 camera pixels/cell the receiver should now accumulate 3–4 observations, make RS attempts, and show non-zero calibration-separation diagnostics instead of remaining indefinitely at `Temporal attempts = 0`.

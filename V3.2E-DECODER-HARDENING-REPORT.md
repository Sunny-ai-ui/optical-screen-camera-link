# V3.2E — Receiver Decoder Hardening

## Scope

This phase intentionally keeps the optical link one-way. No reverse communication channel, ACK path, or receiver-controlled sender switching was added. The work is limited to making the existing V3 receiver more tolerant of real camera/display impairments.

## Implemented

1. **Sub-pixel timing phase refinement**
   - Coarse phase search is followed by quarter-pixel refinement.
   - A small correction penalty prevents flat timing plateaus from drifting toward a cell edge.

2. **Bilinear optical sampling**
   - Timing and solid-cell samples can be measured at fractional positions.
   - This makes sub-pixel phase estimates useful instead of purely nominal.

3. **Live RGB channel normalization**
   - The four V3 colour calibration cells are used to estimate bounded per-channel gains.
   - Data-cell colour classification uses the normalized chromatic space.

4. **Local background shape decoding**
   - Shape extraction now compares the glyph against the cell's observed local chromatic background rather than only the global calibration colour reference.
   - This reduces shape errors caused by local exposure, tint, glare, or brightness variation.

5. **Higher-resolution shape features**
   - Shape features use a 5×5 spatial descriptor rather than the previous 3×3 descriptor.
   - The live shape calibration row remains the reference, preserving camera-specific adaptation.

6. **Absolute-fit-aware confidence**
   - Colour and shape confidence now combine nearest/second-nearest margin with absolute fit quality.
   - A bad sample can no longer receive high confidence merely because it is slightly less bad than the next candidate.

7. **Calibration-driven decoder gates**
   - Learned channel quality derives bounded timing and signature acceptance gates.
   - Default conservative gates are retained while calibration is still learning.

8. **Calibration-aware confidence scaling**
   - Observations that are materially weaker than the learned channel baseline have their cell confidence reduced before temporal fusion/RS erasure selection.
   - The wire format and RS implementation are unchanged.

9. **New physical-decoder diagnostics**
   - Low-confidence cell rate.
   - Colour calibration separation.
   - Shape calibration separation.
   - Current decoder timing gate.
   - Current decoder signature gate.
   - Calibration confidence scale.

10. **Synthetic image decoder validation**
    - A complete G32 optical frame is rendered to ImageData, passed through a deliberate RGB channel shift, optically decoded, RS recovered, and verified byte-for-byte.

## Validation

- Full regression suite: **81/81 passing**.
- Temporal benchmark: three individually RS-uncorrectable observations fuse to a clean recovery with **0 remaining corrected symbols**.
- Fountain benchmark: **20/20** recovered at 0%, 10%, 20%, and 30% complete optical-frame loss in deterministic simulation.
- Synthetic camera-like RGB shift image test: successful byte-for-byte V3 recovery.

## Preserved

- Temporal fusion.
- Web Worker decoder path.
- G32/G48/G64 profiles.
- RS(15,11) and interleaving.
- Packet CRC.
- Fountain transport.
- Adaptive sender-setting recommendations.
- Classic transport fallback.
- Legacy receiver mode.
- Debug snapshot export.

## Explicitly not implemented

- Reverse optical communication.
- Receiver ACK channel.
- Receiver-to-sender automatic control.
- Bidirectional profile negotiation.

## Recommended physical test

Start with G32 + Resilient Fountain + Auto Reliable + 100% extra fountain droplets. Keep the device geometry stable until calibration is ready. Then compare low-confidence cell rate, colour/shape calibration separation, timing/signature gates, RS rejects, and transfer completion while varying distance, angle, brightness, and ambient light.

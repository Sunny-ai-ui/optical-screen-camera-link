# V3.2D Physical Channel Calibration & Auto Link Optimization

## Scope

V3.2D adds a receiver-side learning layer on top of V3.2C without changing the optical wire format. The receiver now learns the physical channel from rolling observations and successful/failed decodes, then uses that evidence to tune its acceptance gate and recommend safer/faster sender settings.

## Implemented

- Rolling channel calibration window.
- Learned frame-quality acceptance threshold with conservative bounds.
- Median timing/signature baseline tracking.
- Rolling shape/colour/combined confidence tracking.
- Measured decode-success rate.
- Link optimizer recommending profile, dwell time, and fountain redundancy.
- Receiver metrics exposing calibration and optimization state.
- Debug snapshots now include the calibration summary and optimizer decision.
- Sender fountain redundancy selector for applying receiver recommendations manually.
- Existing V3.2C temporal fusion, RS, fountain transport, G32/G48/G64 profiles, and legacy fallback remain intact.

## One-way-link rule

The current optical link is sender-to-camera only. Therefore V3.2D does not pretend to remotely reconfigure the sender. The receiver automatically tunes receiver-side evidence acceptance and produces explicit sender recommendations. Closed-loop automatic sender reconfiguration requires a real feedback channel and remains a later phase.

## Recommended physical test

1. Start with G32 + Resilient Fountain + Auto Reliable dwell + 100% redundancy.
2. Hold geometry and lighting stable for at least 10–20 usable observations.
3. Wait until Calibration changes from `learning` to `ready`.
4. Observe optimized profile, dwell, and fountain redundancy recommendations.
5. Apply the closest sender settings and continue transfer.
6. Save a Debug Snapshot if the link degrades; the JSON now contains learned channel statistics.
